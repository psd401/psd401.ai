The Open
Adaptive District

A public school district built to absorb new technology at the pace technology actually moves — through cross-silo teams, short cycles, common intent, and a learning published as it happens.

Draft Collection · May 2026

What this is. This is the working set of documents that defines and operates the Open Adaptive District at Peninsula School District. The doctrine, the cycle, the agent, the templates, the briefs, the training, the action plan — all gathered in one place so any district can read it, fork it, and adapt it.

Where to begin. Start with the SHIP Quick Guide for the doctrine, then read The Logbook to see how it operates. Everything else is templates, training, and worked examples that hang off those two.
